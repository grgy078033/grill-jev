# Presentation Contract

Never collapse the output into "Jev says B, so choose B."

Present three distinct layers.

## 1. Jev Evidence

Show:

- overall Choice distribution;
- relevant dimension scores;
- hard-constraint warnings;
- candidate coverage probability;
- notable uncertainty.

## 2. Agent Recommendation

The parent agent may explain trade-offs and recommend an option, but it must identify that reasoning as its own. It may disagree with Jev.

## 3. User Decision

Ask the user to choose from the candidate set or propose another option.

Example:

```text
Jev Evidence
- A: 18%
- B: 55%
- C: 27%
- B scores strongest on NPC integration, but has elevated scope risk.

Agent recommendation
- I recommend a hybrid D: manual early game, NPC delivery after progression.

Your decision
- A / B / C / D / Other
```

Probability is evidence, not authority.
